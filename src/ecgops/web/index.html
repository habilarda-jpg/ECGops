Expected input format

Pre-segmented single heartbeats: 187 samples at 125 Hz (1.5 s, zero-padded at the end), scaled to [0, 1]. One beat per row with 187 columns, or 188 when the last column is the label (0 = normal, 1 = abnormal), no header. Raw ECG recordings are not supported.
